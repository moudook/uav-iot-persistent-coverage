## Rules for reviewers

- READ ONLY on the repository. Do not edit `.tex`, `.csv`, `.json`, `.py`.
  Your only write is your own findings file under `Project1/reviews/`.
- Do not start training runs (each takes 10+ minutes and the machine is busy).
  Short python that only reads CSVs/JSONs and recomputes statistics is fine.
- Do not install packages.
- Every finding must be falsifiable: give `file:line`, the exact text or value you
  object to, the exact artefact field/expression it should equal, and what you
  computed. A finding without that evidence will be discarded unread.
- Mark each finding `CONFIRMED` (you ran something / read the exact value) or
  `SUSPECTED` (you reasoned it, could not check). Do not blur the two. Being wrong
  loudly is worse than being empty.

# Archive

This directory preserves material that is no longer part of the active
workflow: prior papers, decks, drafts, audits, external reviews, research
notes, and supervisor feedback.

These files are kept for provenance, not as current results. Numbers in them
may predate the corrected shaping sign, the corrected degraded-service term,
the movement-waste redefinition, the corrected energy certificate, or the
second-generation retrain.

The full paper can be rebuilt from `full-paper/` with:

```powershell
cd docs/archive/full-paper
pdflatex Mlawn-midsem-tex.tex
```
